# crpsp-abnt

Estilo biblatex que estende o `biblatex-abnt` para a ABNT NBR 6023:2018 e a
NBR 10520:2023: documento jurídico (legislação, jurisprudência, ato
administrativo), citação autor-data acessível e mídia contemporânea.

**Estado:** planejado, sem código. O plano, a linha de base medida e as
decisões estão em [`briefings/briefing-crpsp-abnt.md`](briefings/briefing-crpsp-abnt.md).

A sondagem que mediu o upstream está em `desenvolvimento/sondagem/`.
