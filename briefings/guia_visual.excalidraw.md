em que apenas a faixa traz imagens (o resto é transparente).

```
\AddToShipoutPictureBG{%
    \ifodd\value{page}%
        \AtPageLowerLeft{%
            \includegraphics[width=\paperwidth, height=\paperheight,
                alt={}]{bg-impar.pdf}}%
    \else%
        \AtPageLowerLeft{%
            \includegraphics[width=\paperwidth, height=\paperheight,
                alt={}]{bg-par.pdf}}%
    \fi%
}
```
